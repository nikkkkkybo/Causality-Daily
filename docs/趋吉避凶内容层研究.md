# "趋吉避凶"每日小建议：跨文化内容层研究

> 日期：2026-11-13　状态：研究 / 内容层设计稿
> 定位：不是算命，也不是"今日运势"；是**个人因果基线 + 当日信号 + 小型可逆行动**的条件性建议。
> 输出格式：每天最多 3 条，分「宜 / 忌 / 观察」，每条必须有理由、证据、验证方式与有效期。

---

## 0. 先把"吉凶"翻译成可做的东西

| 传统说法 | 我们翻成什么 | 不能变成什么 |
|---|---|---|
| 吉 | 条件顺、阻力小、可行动 | "今天一定成功" |
| 凶 | 风险/约束/波动大，先避开 | "今天一定出事" |
| 宜 | 在某个领域做某类小行动 | 命令、投资/医疗/法律建议 |
| 忌 | 暂缓不可逆决定，或换一种做法 | 恐吓、宿命论 |
| 择日 | 选时间窗（现实截止日 + 个人状态） | 精确到分钟的"吉时"承诺 |

一句话：**"趋吉避凶"在我们的内容层 = 条件性决策卫生**，不是预测。

---

## 1. 跨文化、跨时期的"每日建议"系统集合

### 1.1 中国：黄历 / 通书 / 择日

- **形态**：每日"宜/忌"清单，按活动分类（嫁娶、出行、动土、开市、入学、祭祀等）；配套建除十二神、二十八宿、神煞、干支。
- **逻辑**：日期/干支/神煞 → 活动适配度；《协纪辨方书》是清代官方集大成，民间通书更简化。
- **可借**：**活动分类 + 宜/忌二元 + 时间窗**；把"嫁娶/动土"换成"沟通/签约/学习/休息"等现代动作。
- **不可借**：把神煞当事实、把"宜"当保证、把"忌"当恐惧。
- 参考：[大崎八幡宮·六曜/十二直/二十八宿说明](https://www.oosaki-hachiman.or.jp/calender/mean/)、[宋鲁珍通书研究（台大）](https://scholars.lib.ntu.edu.tw/server/api/core/bitstreams/b58edafc-24f4-454f-8b8d-ee8589b514bd/content)

### 1.2 中国：紫微斗数 / 八字流日

- **形态**：以本命盘/四柱为基线，叠加流年/流月/流日，判断某领域"被激活"；现代 App 常输出"今日事业/感情/财运"。
- **逻辑**：基线 + 时间分片 + 关系语法；不是事件预言。
- **可借**：**领域激活/注意力分配**——今天哪个领域值得多看一眼；只做排序，不输出"会发生什么"。
- **不可借**：具体事件、吉凶断定。

### 1.3 中国：六爻 / 梅花 / 小六壬 / 灵棋经 / 签诗

- **形态**：每日一卦/一签/一时课；输出象、辞、吉凶倾向。
- **逻辑**：时间/随机触发 + 象征解释；强调"所问之事"。
- **可借**：**每日一个反思问题**（"今天最该问自己的是什么"），以及"一事一议"的聚焦。
- **不可借**：把随机结果当客观预测。

### 1.4 日本：六曜 / 十二直 / 九星気学

- **六曜**：先胜（上午宜急事）、友引（朝夕吉、午后凶、忌葬）、先负（宜静、午后大吉）、佛灭（万事凶、慎口舌）、大安（诸事大吉）、赤口（诸事谨慎、正午仅吉）。
- **十二直**：建/除/满/平/定/执/破/危/成/收/开/闭，按日循环，对应活动宜忌。
- **九星気学**：日盘/月盘，吉方位与行动建议。
- **可借**：**日语气氛 + 活动分类**（"今天适合整理/不适合硬推"），以及"方位/环境"作为提醒。
- **不可借**：把六曜当命运；同一天对所有人都一样，违背"个体因果"。
- 参考：[大崎八幡宮·暦の意味](https://www.oosaki-hachiman.or.jp/calender/mean/)

### 1.5 印度：Panchang / Muhurta / Jyotish

- **形态**：每日 Panchang 给出 tithi（月相日）、nakshatra（宿）、yoga、karana，以及吉/凶时段；Muhurta 用于择时。
- **逻辑**：天文时间 + 活动适配；高度依赖历法计算与地方传统。
- **可借**：**时间窗 + 活动适配**的结构；"什么时候做"比"会发生什么"更有用。
- **不可借**：具体事件预测；不同流派差异极大。
- 参考：[MyPanchang Tarabalam](https://www.mypanchang.com/newsite/tarabalamchakra.php)

### 1.6 西方：选举占星 / 行星时 / 年历 / 每日星座

- **Electional astrology**：为具体行动选时间（结婚、开业、旅行），看上升、月亮、行星相位；1937 年 Robson 的《Electional Astrology》是经典文本。
- **Planetary hours**：把一天切成行星时，某些时"适合"某类行动。
- **Almanac / daily horoscope**：每日/每周太阳星座建议；受众广，但 Barnum 效应强。
- **可借**：**"择时"而非"预言"**；把"吉时"降级为"你状态更好的时间窗"。
- **不可借**：星座决定论、巴纳姆式模糊描述。
- 参考：[Robson, Electional Astrology (1937)](http://iapsop.com/ssoc/1937__robson___electional_astrology.pdf)、[Popular Horoscopes and the Barnum Effect](https://www.tandfonline.com/doi/abs/10.1080/00223980.1983.9915405)

### 1.7 其他传统与现代实践

- **西非 Ifa / 贝壳占卜、北欧符文、塔罗日抽**：每日一象，用于反思与聚焦；结构上都是"触发 → 象征 → 行动提示"。
- **现代 decision journal / N-of-1 / implementation intentions**：记录决定、结果、置信度；用个人数据检验建议是否有用。
- **可借**：**每日一记 + 前后对比 + 小实验**，这是把"吉凶"变成可验证内容的关键。
- 参考：[N-of-1 个体因果推断](https://zenodo.org/records/17932200)

## 2. 它们的共同"内容语法"

不管哪套系统，落到每日建议，基本只有六个槽位：

| 槽位 | 含义 | 我们的字段 |
|---|---|---|
| 时间 | 今天/某时段 | `window` |
| 领域 | 事业/财务/健康/关系/学习… | `domain` |
| 条件 | 顺/逆/不确定 | `condition` |
| 动作 | 做什么/不做什么/观察什么 | `kind: 宜/忌/观察` + `action` |
| 依据 | 为什么是这条 | `why` + `evidence` |
| 不确定性 | 置信度/失效条件 | `confidence` + `expires` + `verify` |

传统系统强在"时间 + 领域 + 宜忌"的封装；弱在"个人化"和"可验证"。我们要保留前者，补上后者。

## 3. 内容层设计：每日小建议怎么生成

### 3.1 输入

1. **因果强潜意识**（本地档案）：领域权重、目标、约束、杠杆、位置、心理负荷、改变阶段；
2. **当日上下文**：日期/星期、个人日历、近期备注（意向层）、外部信号（新闻/政策/价格）；
3. **可选**：出生数据（只作隐藏时间标签，不输出命理结论）。

### 3.2 生成步骤

```text
① 读基线：哪些领域重要、哪些不能动、当前负荷/阶段
② 读当天：有哪些信号落在这些领域；有没有时间窗/截止日
③ 生成候选条件：
   - 机会：条件顺 + 有可行动作
   - 风险：约束/波动 + 不可逆动作
   - 观察：信号弱/矛盾，先别动
④ 过滤：
   - 只保留小型、可逆、今天能做的动作
   - 剔除医疗/投资/法律/不可逆决定
   - 没有"依据"的不发
⑤ 排序：与领域权重 × 时效 × 可行动性
⑥ 输出最多 3 条：宜 / 忌 / 观察
```

### 3.3 内容对象（建议 schema）

```json
{
  "kind": "宜|忌|观察",
  "domain": "career|wealth|health|relationship|family|learning|social|inner",
  "action": "一句可执行的小动作，≤40 字",
  "why": "与你的哪个目标/约束/信号有关，≤80 字",
  "evidence": ["I#12", "profile.goal", "note:2026-11-12"],
  "confidence": "低|中|高",
  "reversible": true,
  "expires": "2026-11-13",
  "verify": "今天/本周怎么看出有没有用"
}
```

### 3.4 文案规则

- 宜：**条件顺 + 动作小**；例："上午先写 45 分钟，不接新消息。"
- 忌：**不是禁止，而是"暂缓/换法"**；例："今天先不做不可逆承诺，等负荷降下来再谈。"
- 观察：**承认不知道**；例："留意这条供应链消息是否影响你的采购成本，先别下结论。"
- 每条必须能回答："为什么是我？为什么是今天？怎么验证？"
- 不出现："命中注定、必有、大凶、保证、一定"。
- 不出现具体医疗/投资/法律指令；高风险只提示"找专业人"。

### 3.5 示例（虚构档案）

> 档案：事业权重高、时间约束强、当前负荷高、目标"把工作从执行转向定义问题"。

- **宜**：上午先做 45 分钟"定义问题"的写作，别先回消息。  
  *依据：事业权重 0.9；你负荷高，先做需要自主思考的事；昨天的备注提到"想多留意思路"。*
- **忌**：今天暂缓对同事做不可逆的评价/承诺。  
  *依据：负荷高 + 关系领域权重中；不是不能沟通，而是换到明天低负荷时。*
- **观察**：供应链新闻是否影响你手上的采购/交付节奏。  
  *依据：经济领域权重中；信号未核验，先记录，不行动。*

## 4. 放进《今日事报》的位置

- 放在**链之后、算法链之前**，独立小节「今日小建议」；
- 不与因果链混写：链是"世界→结构"，建议是"你的条件→小行动"；
- 周报里做「本周建议复盘」：哪条做了、有没有用、下次改什么；
- 云端通线没有档案 → **不生成个体建议**；只有本地个体线，或云端拿到非敏感派生特征后才生成。

---

## 5. 验证：别让它变成星座运势

1. **N-of-1**：每条建议记录"是否执行 / 有用 / 有害"，两周后回看；
2. **盲评**：同一档案，给"有建议"与"无建议"两版，比较是否更有行动价值；
3. **消融**：关闭"命理先验"、关闭"个人基线"、关闭"当日信号"，看建议质量变化；
4. **反巴纳姆检查**：建议必须具体到领域/动作/时间；"你最近有点累"这类不发；
5. **失败样本**：保留"这条建议错了"的记录，作为规则修订依据。

---

## 6. 实施顺序（建议）

1. **本地规则版**：`advice.py` 从档案 + 当日日报信号生成 1–3 条；先不接模型；
2. 在本地 `daily --brief/--html` 增加「今日小建议」；
3. 用 2 周 N-of-1 收集"执行/有用/有害"；
4. 稳定后再接 DeepSeek 改写（仍受同一 schema 约束）；
5. 云端个体建议需要先同步**非敏感派生特征**；保险箱不出本地。
