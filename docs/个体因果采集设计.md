# 个体因果采集设计：问卷、前置准备与"保险箱"

> 状态：研究 + 设计稿　日期：2026-11-12
> 目的：把"个体因果层"需要的个人基线，做成**可提前填写、可跳过、可封存**的采集流程，而不是在对话里临时盘问。
> 参考：Dan Koe 的 HUMAN 3.0 框架（社区修订版提示词）及其实践案例；隐私分级参考"敏感数据保险箱"的通用做法。
> 边界：HUMAN 3.0 是**反思框架，不是经验证的测评**；本设计不诊断、不评分、不预测命运、不提供医疗/法律/投资建议。
> **v2 修订（2026-11-12）**：上一版问卷基本照搬 HUMAN 3.0。经源流审查（见 [源流与整合](源流与整合.md)），HUMAN 3.0 本身是 Spiral Dynamics、Wilber AQAL、Loevinger 自我发展、心流、古代哲学与职业理论的二次合成；本版把四象限降为"三视角之一"，新增"因果位置（命理语法，去术语）"与"心理与行为基线（心理学）"两部分，并为每个条目标注来源与失效模式。

---

## 0. 结论

1. **采集应是一次性的"前置问卷 + 周期复评"**，不是在推送时提问；问卷先建基线，之后只从事报末尾备注做微调。
2. **借 HUMAN 3.0 的结构**：四象限（心智/身体/精神/职业）× 三层级（1.0 从众 / 2.0 个人 / 3.0 综合）× 三阶段（不和谐/不确定/发现）；用"问题解决"视角定位当前阶段与核心问题。
3. **借它的访谈纪律**：一次一问、可跳过/暂停/停止、证据锚定、未知保留、不给数字分数、先给摘要再给完整报告、6 个月复评。
4. **不借它的高风险建议**：Glitch（迷幻药/PED/故意制造财务压力等）相关内容一律不进入我们的采集与推送；不把层级当作"安全许可"。
5. **隐私做成四层**：可回答 / 本地私密 / 保险箱（默认不读取）/ 永不采集；敏感题默认"只存保险箱"，不答也能跑。
6. **产出**：一份"个人因果基线报告"（定性、可纠正、无分数）+ 一段确认对话（你改，我记）+ 之后的个性化事报（"为什么与你有关/你在哪一段"）。

## 1. HUMAN 3.0 的可借机制（研究摘要，v2 已降为三视角之一）

HUMAN 3.0 把人生分成四个象限：

- **Mind（心智）**：思想、情绪、信念、世界观、元认知、知识合成；
- **Body（身体）**：健康、体能、营养、睡眠、能量、外在行为；
- **Spirit（精神）**：关系、社群、意义、文化/传统/超越；
- **Vocation（职业）**：经济与社会参与、职业/商业、系统与机构、影响与遗产。

每个象限有三层意识（1.0 从众者、2.0 个人主义者、3.0 综合者），层内有三阶段（不和谐、不确定、发现），并用知识/经验/技能三种"特质"衡量横向发展；"通道"是深度沉浸期，"故障"是高风险加速器。

它的评估提示词里，有几条纪律值得直接借用：

- **自适应访谈**：每象限 3–8 个问题，一次只问一个；允许跳过/暂停/停止；证据不足就留白，不硬填。
- **证据锚定**：每个重要判断都要引用用户的原话/转述，区分"用户说的"与"我的解释"，并标注高/中/低置信度与替代解释、未知项。
- **不评分**：明确"不计算发展分数、不显示百分比"；框架是反思辅助，不是验证过的测评。
- **不诊断、不承诺**：不声称能测准发展、不看穿隐藏真相、不从有限回答推断因果；不把层级当作高风险行为的安全许可。
- **先摘要后报告**：访谈完先给简短摘要，用户确认/纠正后再给完整报告。
- **复评周期**：建议约 6 个月后重评。

这些恰好可以转成"自填问卷 + 摘要确认"的离线流程。

### 1.5 源流审查（v2 新增）

HUMAN 3.0 的提示词自述其来源：Spiral Dynamics、Ken Wilber 的 AQAL、自我发展九阶段（Loevinger/Cook-Greuter 一系）、心流心理学、古代哲学、现代职业理论；Dan Koe 再把它压缩成四象限 × 三层的流行框架。

这意味着：

- 直接照搬 HUMAN 3.0 = 抄一份**二手压缩包**，会继承它的层级简化、原型标签化与未验证性；
- 它缺的正是命理/心理学各自擅长的东西：命理给**领域/时间/关系/主体—客体**的细粒度语法；心理学给**测量、行为改变、信效度与纠错**；
- 因此 v2 把 HUMAN 3.0 降为"当前问题/阶段"的假设来源之一，不再作为问卷主结构。

详细源流、批评与三源对照见 [源流与整合](源流与整合.md)。

## 2. 与"个体因果层"的接口

HUMAN 3.0 回答的是"**你处在哪个阶段、正在解决什么问题**"；命理结构回答的是"**你的领域、时间与关系语法**"。两者都不做预测，只做假设生成。

### 2.1 两条线与"强潜意识"（v2 新增）

- **通线（general）**：没有基线时，按"一个关心因果、需要判断的读者"来推；不假装懂你。
- **个体线（individual）**：有基线时，把领域、时间、约束、杠杆当作**强潜意识**——影响候选池、排序与呈现，但不以命令/档案形式出现。
- **轻个体线（partial）**：只有领域权重或当前问题；只影响排序，不加"你在哪一段"。
- **强 vs 弱**：强潜意识＝基线（持久、高权重、半年复评）；弱潜意识＝事报末尾备注/偶发话（短期、低权重、快速衰减）。
- **降级**：基线缺失/过期/重大生活事件 → 先回通线，复评后再升；任何结论不能落到可观察后果就不写。

详细分层、排序公式、防回音室与实施顺序见 [整合架构与双线](整合架构与双线.md)。

| 采集到的内容 | 进入个体因果层的哪一部分 |
|---|---|
| 四象限当前层级/阶段（定性） | 当前阶段、核心问题、注意力权重 |
| 各象限的强弱与"阻塞" | 领域权重、脆弱点（不可行动区） |
| 知识/经验/技能差距 | 可行动性与杠杆点 |
| 目标、约束、近期事件 | 个体因果图的节点与边 |
| 信息习惯、判断方式 | 推荐形态（深/浅、早/晚、证据密度） |
| 领域权重与时间窗口 | 排序分中的 weight/timeliness |
| 出生数据（可选、保险箱） | 仅用于"时间层"的内部标签，不输出命理结论 |

## 3. 数据分层：哪些可回答，哪些进保险箱

### 3.1 四层

| 层 | 名称 | 默认处理 | 例子 |
|---|---|---|---|
| **A** | 可回答（参与排序） | 本地保存，参与领域权重与排序；可在脱敏后进入外部模型 | 时区、作息、领域权重、非敏感目标/约束、信息习惯、判断偏好、什么算"有用" |
| **B** | 本地私密（参与排序，不外发） | 本地保存；只生成粗粒度派生特征；默认不发给外部模型 | 近期个人事件、睡眠/精力、家庭状态（粗）、财务压力（高/中/低，不给金额）、关系状态（粗） |
| **C** | 保险箱（默认不读取） | 加密保存；默认不参与任何计算；仅在用户针对某个问题**临时解锁**时读取；永不外发 | 出生日期/时间/地点、健康细节、家庭/关系细节、收入/资产/负债、法律纠纷、创伤经历 |
| **D** | 永不采集 | 不收集、不存储 | 身份证号、账号密码、第三方隐私、病历原件、精确账户、他人敏感信息 |

### 3.2 每题的四种回答模式

- **回答**：进入对应层；
- **只存保险箱**：原样加密保存，默认不参与；
- **不回答**：记为"未提供"，不影响继续；
- **不知道/说不清**：记为"不确定"，不推断、不补全。

> 默认值：敏感题默认选中"只存保险箱"，普通题默认"回答"；所有题都可跳过。

### 3.3 派生特征（只从 A/B 生成）

- 领域权重：`career/wealth/health/relationship/family/learning/social/home/inner` 各 0–1；
- 当前阶段：`disharmony/uncertainty/discovery`（定性）；
- 核心问题：一句话（来自本人选择或确认，不由系统代填）；
- 约束：`time/money/energy/obligation/skill/access` 哪些成立；
- 杠杆：本人确认的 1–3 个可动资源；
- 时间窗：真实截止日/周期（不是命理预言）；
- 信息偏好：深读/速览、早间/晚间、证据密度、是否要反方观点。

### 3.4 安全与工程

- **本地优先**：问卷与档案只存本机；导出需本人操作。
- **保险箱加密**：Windows 用 DPAPI（当前用户绑定）或独立口令加密；不写明文日志。
- **最小化**：只存派生特征时，原始答案可删除；C 层原文不参与训练/推送。
- **同意与审计**：每次解锁 C 层需一次明确动作并记录（谁、何时、为何）；可随时删除/导出。
- **外部模型**：只发 A 层与 B 层的粗粒度派生特征；C 层永不发送；发送前脱敏并提示。
- **不做**：不推断未提供的信息；不用出生数据做命理结论；不做医疗/法律/投资建议；不把层级当安全许可。

## 4. 问卷结构（建议分两次填，总计 30–45 分钟）

### Part 0 · 基础与同意（3–5 分钟，A）
- 时区、常用作息（起床/工作/休息）；
- 你希望事报在什么时间、以什么长度出现；
- 同意条款：本地保存、可跳过、保险箱规则、删除/导出方式；
- 选择默认隐私档（保守/标准/开放）。

### Part 1 · 四象限自评（15–25 分钟，A/B）
每象限 3–6 题，按 HUMAN 3.0 的"层级/阶段/特质"设计，但只做定性，不评分。**v2 起仅作假设，不贴标签、不判断层级高低。**

> 来源标注：`H` = HUMAN 3.0（假设）；`M` = 命理语法（去术语）；`P` = 心理学（测量/行为/验证）；`A` = 通用基线。每个条目还应在实现时补"用途/失效模式"。

**Mind（心智）**
1. 遇到与你世界观冲突的信息，你第一反应是什么？（A）
2. 你如何判断一条信息"可信/有价值"？（A）
3. 最近一次重大观点改变是什么触发的？（B，可保险箱）
4. 哪些概念你能解释但做不出来？（知识 vs 经验）（A）
5. 哪些事曾经费力、现在自然？（技能）（A）

**Body（身体）**
1. 你与身体的关系：盟友/敌人/工具？（B）
2. 健康决策主要由什么驱动：外观/表现/长寿？（A）
3. 生活混乱时，你的身体习惯能保持多少？（B）
4. 当前睡眠/精力水平（粗粒度：低/中/高）。（B）

**Spirit（精神）**
1. 一切都没意义时，你如何获得意义？（B，可保险箱）
2. 你与社群的关系：必要/可选/不可或缺？（A）
3. 你对"绝对真理 vs 相对视角"的立场？（A）
4. 你最近一次感到"被理解"是什么时候？（B，可保险箱）

**Vocation（职业）**
1. 工作对你来说是"做的事/拥有的东西/你本身"？（A）
2. 你如何衡量职业成功：薪水/影响/成就感？（A）
3. 如果钱和地位无关，你会做什么？（B）
4. 当前最大的职业约束是什么？（时间/资金/能力/授权/关系）（B）

### Part 1.5 · 因果位置（8–10 分钟，A/B；来源 M，去术语）

借"体用/世应/生克/用神"的语法，只问生活语言：

1. 在你在意的事情里，你通常是：主动方 / 被动受影响 / 旁观者 / 多重角色？（M）
2. 你现在最想守住或推进的是什么？（"体"）（M）
3. 当前最牵动你的"外部之事"是什么？（"用"）（M）
4. 这件事对你更像：增益 / 消耗 / 同类 / 说不清？（生克/比和）（M）
5. 你关注的时间窗：周 / 月 / 季 / 年？（M）
6. 你身边主要的关系力（多选）：资源 / 规则 / 竞争 / 表达 / 学习 / 庇护 / 说不清？（十神/四化类比）（M）
7. 你现在的角色/位置：家庭、组织、行业、地域（只写范围）。（B）

失效提醒：这些只是**关系假设**，不能据此断定吉凶或具体事件；多派歧义与出生时间敏感都要保留。

### Part 2 · 个体因果基线（8–12 分钟，A/B）
1. 你现在处在什么阶段？（不和谐/不确定/发现）——用一句话描述；
2. 未来 3–6 个月最想推动的一件事；
3. 为此你能动用的 1–3 个资源/能力（杠杆）；
4. 哪些事是你"不能/不敢/没时间"做的（约束）；
5. 最近 1–3 个月发生的、可能影响判断的事（B，可保险箱）；
6. 你最希望系统替你盯住哪类因果：风险/机会/人/政策/技术/健康/关系；
7. 什么算"这条推送对我有用"：提前知道/少踩坑/做出决定/理解结构；
8. 你能接受的事报长度与频率；是否要反方观点；
9. 你是否愿意提供出生日期/时间/地点（可选，默认保险箱）；
10. 你希望"个体因果"显式写在每条链里，还是只影响排序（默认显式一句"为什么与你有关"）。

### Part 2.5 · 心理与行为基线（6–8 分钟，A/B；来源 P）

只取可回答、可复测、非诊断的条目：

1. 价值观 top 3（Schwartz）：自我导向 / 刺激 / 享乐 / 成就 / 权力 / 安全 / 顺从 / 传统 / 仁善 / 普遍主义；（P）
2. 面对当前目标，你的信心（自我效能）1–5；（P）
3. 当前负荷/压力 1–5；（P）
4. 改变阶段：没想 / 在想 / 准备 / 行动 / 维持；（P）
5. 社会支持 1–5；（P）
6. 财务压力：低 / 中 / 高（不给金额）；（B）
7. 睡眠：低 / 中 / 高。（B）

失效提醒：自评量表有社会赞许偏差、文化偏差、状态波动；不作诊断、不贴人格标签、不单独决定推送。

### Part 3 · 隐私与边界（3–5 分钟，A）
- 逐项选择：A 可回答 / B 本地私密 / C 保险箱 / D 不采集；
- 是否允许脱敏后的派生特征进入外部模型（默认否，需明确开启）；
- 是否允许保存原始答案（默认只保存派生特征，原始答案可删）；
- 复评提醒周期（默认 6 个月）。

### Part 4 · 产出与确认（问卷后）
系统生成：
1. **个人因果基线报告（摘要版）**：1 页，定性描述当前阶段、领域权重、核心问题、约束、杠杆、建议的推送形态；**无分数、无命理术语、无诊断**。
2. **确认对话**：你可以改任何一条；系统只记录你的确认/修正，不替你做结论。
3. **7 天校准**：每天事报末尾问一句"今天这条与你有关吗？"（可选 A/B/C），一周后微调权重。
4. **6 个月复评**：与首次结果对照，只看变化，不评分。

## 5. 问卷的"反模式"检查（避免变成算命/心理测试）

- 不出现"你是 X 型人格"这种固定标签；只出现"当前阶段/当前问题"的可变描述。
- 不计算总分、不排名、不给百分比；内部权重不展示。
- 不把模糊普适的描述当"说中了你"（巴纳姆效应）；报告必须引用你实际说过的内容。
- 不推断未答内容；"不知道"就写不知道。
- 不把高风险行为（药物、极端财务、重大不可逆决定）纳入建议；遇到相关表述只提示寻求专业帮助。
- 不把出生数据用于预测；最多作为内部"时间标签"，且默认关闭。
- 不做医疗/法律/投资建议；不替你做决定。

## 6. 验证与迭代

1. **问卷层**：10–20 人小样本预填，观察完成率、跳过率、题目歧义、复测一致性（两周重测）；题目宁少勿多。
2. **档案层**：让本人对"基线报告"逐条确认/修正；修正率高的条目重写。
3. **推送层**：N-of-1 + 盲评——个体化排序 vs 通用排序，比较"值得看/有解释力/促进行动"；每月复盘。
4. **消融**：分别关闭领域权重、约束、时间层，看效果变化；无增量就降权。
5. **复评**：6 个月一次；只记录变化与问题迁移，不评分。

## 7. 实施顺序（建议）

1. **静态问卷原型**（本地 HTML，自包含，无后端）：先给 15 分钟"核心版"（Part 0–2 的精简题），填完导出 JSON；敏感题默认保险箱。→ 已落地 v2：[app/questionnaire.html](../app/questionnaire.html)（含因果位置与心理行为基线，三源标注 H/M/P）。
2. **JSON 导入 + `profile` 表**：只落地派生特征；原始答案可留在导出文件里，由本人保管。
3. **个体因果排序 MVP**：领域权重 + 目标/约束 + 时间窗 → 对每日候选打分；事报加"为什么与你有关/你在哪一段"。
4. **保险箱**：DPAPI/口令加密；解锁审计；删除/导出。
5. **周期复评与验证**：7 天校准、月度盲评、6 个月复评。

## 8. 需要未来确认（不是现在问）

- 你愿意填"核心版"还是"完整版"；哪些题默认进保险箱；
- 是否允许脱敏派生特征进入外部模型；
- 出生数据是否提供（可选）；
- 复评周期。

这些问题会写进问卷本身，由你在填写时选择，不需要在对话里逐条回答。
