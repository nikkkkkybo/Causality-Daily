## 2. 关键证据一：《御定星历考原》自己说"神煞莫知所起"

《御定星历考原》提要（康熙五十二年御定，乾隆四十六年校上）原文：

> "并取曹振圭《历事明原》，诏大学士李光地等重为考定，以成是编……  
> 然**神煞之说则莫知所起**……则神煞之说**自汉代已盛行矣**……  
> 历代方技之家所传不一，**辗转附益，其说愈繁**。"

这段话非常重要：

- 它不是我们今天的"外部批评"，而是**清代官方编纂者自己承认**：
  1. 神煞的源头**不知道**；
  2. 汉代已盛行；
  3. 历代不断**附益**，越滚越大。
- 这正是"源头/因"的答案之一：**不是一次启示，而是长期汇编与附益。**

### 与 `cnlunar` 引文的直接对照

`cnlunar/book.json` 的"岁德"条目写：

> 《考原》曰："律吕六阳当位自得，六阴则居其冲……"

《御定星历考原》原文对应处：

> "按：律吕六阳当位自得，六阴则居其冲……"

`cnlunar` 还引《曾门经》《广圣历》，这些也出现在《御定星历考原》同一段。  
**结论：`cnlunar` 的《考原》引文不是编的，能对上原典；这条边从 C 升到 B。** 但它仍是"清代汇编"，不是更早的源头。

## 3. 关键证据二：六壬文本到唐代已存在

《大六壬心镜》题：

> "《大六壬心镜》八卷，唐不欲子徐道符撰，宋元迄今，壬家奉为土臬（圭臬）。"

清程树勋手录，序中提到访求十余年、借吕汉枫写本、与程伟堂校勘等。  
**能证明**：至晚清代，六壬有"唐徐道符"传承叙述，且被视为经典；文本群存在。  
**不能证明**：徐道符即作者、唐代原貌、六壬的最终起源。抄本/托名问题仍需版本学。

## 4. 关键证据三：六曜的日本源流

### 4.1 国立国会图书馆参考调查（B）

> "起源は不明ですが、発生は中国で、日本へは十四世紀ごろに伝わりました。その後、江戸時代の終わりごろから流行りだし、第二次世界大戦中の統制を経て、戦後大流行し現在に至ります。"

参考书包括《暦の百科事典》《現代こよみ読み解き事典》（岡田芳朗）、《暦と時の事典》（内田正男）等。  
**能确认**：中国起源、14 世纪传入日本、近世末期流行、战后大流行；**起源不明**。

### 4.2 干支九星研究会（C/B）

> "中国では、六壬時課とか小六壬（李淳風時課）と呼ばれ、時刻の吉凶占いに用いられていました。"
>
> "貞享年間（1684–88）頃から、日本式の日の占いへと変化……名称・順序・解釈とも日本独自のものへと進展……"
>
> "いつ頃誰によって考え出されたかは不明。"

它还给出小六壬/李淳風時課的六神顺序：**大安 → 留連 → 速喜 → 赤口 → 小吉 → 空亡**，以及按月/日/时计数的方法。  
**这解释了"六曜"为什么是六位、为什么顺序如此**，但仍是研究博客，不是同行评议论文。

### 4.3 修正后的链

原来写成：

```text
六曜 ← 六壬時課 ← 六壬 ← 式占/式盘
```

更准确应写成：

```text
六曜（日本式"日"占，17c 末–19c 定型；C/B）
  ← 小六壬 / 李淳風時課（中国"时"占；C/B）
      ←? 六壬時課（名称/功能亲缘；C）
          ←? 大六壬（唐已有文本；B；与小六壬是否同源待证）
              ← 式占/式盘（汉代实物；A/B）
                  ← 阴阳五行/干支/天文（B）
```

关键修正：

- **"六曜来自六壬"是半对**：日本材料说的是"六壬時課/小六壬（李淳風時課）"，不是直接等于"大六壬"；
- 小六壬与大六壬**共享"六壬"之名与术数语境，但可能是不同层级的术法**，不能画成直线；
- 六曜的**名称、顺序、解释是日本改过的**；不是原样搬运；
- 日本参考书自己说"起源不明"；所以"源头"只能到"中国时占传统 + 日本日占改造"，再往上就是"?"。

## 5. 这轮对"因"的更新

1. **文本因**：  
   《协纪辨方书》←《御定星历考原》←《神枢经》《广圣历》《历例》等；  
   但《考原》自己说"神煞莫知所起"，说明这条链在更早处就断了/模糊了。

2. **功能因**：  
   时占（问一件事）→ 日占（给一天定调）→ 历注（印在日历上）→ 民俗（大安结婚、佛灭避事）。  
   功能从"决策"变成"协调"，再变成"习惯"。

3. **制度因**：  
   官方历书/通书/出版/战后商业化，让六曜从术数变成大众日历标签。

4. **认知因**：  
   不确定性 + 需要行动 + 模式识别 + 社会协调；与前两轮一致。

## 6. 仍缺什么

- **日本六曜的同行评议论文**：目前只有 NDL 参考书 + 研究博客；需要找 `六曜 暦注 論文`、`頭書長暦`、`安政雑書万暦大成` 等。
- **《事林広記》《万宝全書》的版本与六壬時課条目**：博客提到，需核对原书。
- **《大六壬心镜》的版本学**：唐托名？清抄本？需馆藏目录。
- **小六壬与大六壬的关系**：共享名称不等于同源，需文本比较。
- **《御定星历考原》的底本**：殆知阁 txt 的来源/校勘需核对四库影印。
