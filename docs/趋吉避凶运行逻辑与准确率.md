# 趋吉避凶系统的运行逻辑与"准确率"来源

> 日期：2026-11-13　状态：分析稿
> 方法：把每个系统拆成 **输入 → 规则/算法 → 输出 → 宣称机制 → 可检验命题**；只看这条"算法链"能不能被验证，不先争论它"神不神"。
> 结论先行：**它们的计算可以很精确，解释可以很自洽，但"预测个人吉凶"的准确率没有可靠对照证据；看起来准，主要来自模糊、选择、社会协调与事后解释。**

---

## 1. 统一拆法：任何一套"趋吉避凶"都逃不出五个槽位

```text
输入（时间/出生/问题/随机）
  → 规则（历法算术 / 象征对应 / 解释传统 / 随机抽取）
  → 输出（宜忌、卦象、运势、方位、建议）
  → 宣称机制（"因为…所以…"）
  → 可检验命题（在什么时间、对谁、预测什么、怎样算错）
```

用这套拆法，传统系统的问题立刻显现：**输入和规则往往很清楚，输出也很具体，但"宣称机制"和"可检验命题"经常是空的或不可证伪的。**

---

## 2. 逐个系统的运行逻辑

### 2.1 黄历 / 通书 / 择日

- **输入**：日期、干支、节气、月建、值日神煞。
- **规则**：历法算术 + 建除十二神/二十八宿/神煞的固定对应表；《协纪辨方书》是官方整理，民间通书是简化版。
- **输出**：某日"宜嫁娶/忌动土"等活动清单。
- **宣称机制**：某神煞/星宿当值 → 某类活动吉凶。
- **可检验命题**：用黄历"宜"的日子做某活动，成功率是否高于随机日？
- **实际情况**：这套系统的"计算"是精确的（历法可复算），但"神煞→吉凶"没有对照验证；不同通书之间还会互相矛盾。
- **准确率来源**：
  1. **活动本身有基础成功率**（大多数婚宴、开业不会出大事）；
  2. **选择性记忆**（顺利归功于择日，不顺归因于别的原因）；
  3. **社会协调**（大家都挑"好日子"，人群聚集、资源紧张，反而制造了可观察的差异）；
  4. **事后解释**（出问题可归咎"没选对时辰"）。
- **可借**：活动分类、时间窗、宜忌二元；**不可借**：神煞决定论。

### 2.2 紫微斗数 / 八字流日

- **输入**：出生时间/地点（+当前时间）。
- **规则**：排盘算法 + 宫位/十神/四化/大运流年的解释规则。
- **输出**：某领域"被激活/有变动"的描述。
- **宣称机制**：命盘结构 + 时间触发 → 个人事件。
- **可检验命题**：给定命盘，预测"某月事业变动"的命中率是否高于基线？
- **实际情况**：排盘是确定性的，解释是多派的；出生时间误差会改变结果；没有预注册、对照、盲评的验证。
- **准确率来源**：
  1. **巴纳姆效应**（描述足够模糊，谁都觉得像自己）；
  2. **多派解释**（总有一种说法能对上）；
  3. **回溯拟合**（事情发生后再找命盘依据）；
  4. **自我实现**（相信"今年有变动"，于是主动换工作）。
- **可借**：领域激活、时间分片、关系语法；**不可借**：具体事件、吉凶断定。

### 2.3 六爻 / 梅花 / 小六壬 / 灵棋经 / 签诗

- **输入**：时间、随机数、所问之事。
- **规则**：起卦/起课算法 + 卦辞/签诗解释。
- **输出**：一个象、一段辞、一个倾向。
- **宣称机制**：随机/时间触发 → 与所问之事对应。
- **可检验命题**：同一问题，盲测多次，卦象与结果的相关性是否高于随机？
- **实际情况**：没有可靠证据支持超常预测；签诗的多义性让"对上"很容易。
- **准确率来源**：
  1. **随机 + 多义**（怎么解释都能沾边）；
  2. **选择性记录**（只记住灵验的）；
  3. **问题本身自带答案**（"我该不该换工作"往往心里已有倾向，卦象只是确认）；
  4. **仪式性承诺**（抽到"宜行动"后真的去行动，结果改善，归功于卦）。
- **可借**：每日一问、聚焦、反思；**不可借**：把随机当预测。

### 2.4 日本六曜 / 十二直 / 九星気学

- **输入**：旧历月日 / 日干支 / 方位。
- **规则**：简单的模运算/循环表（六曜按朔日递推；十二直按日支循环；九星按日期飞泊）。
- **输出**：日语气氛、活动宜忌、吉方位。
- **宣称机制**：日值 → 吉凶。
- **可检验命题**：六曜"大安"日结婚的离婚率/事故率是否更低？
- **实际情况**：六曜是江户以后才普及的历注，计算简单；没有证据支持它预测个人事件。
- **准确率来源**：
  1. **同日同标签，所有人一样**——无法解释个体差异，这本身说明它不是个体因果；
  2. **文化协调**（大安日婚礼扎堆，形成社会事实）；
  3. **基础率与模糊性**；
  4. **确认偏差**。
- **可借**：日语气氛、活动分类的"轻提示"；**不可借**：普适吉凶。

### 2.5 印度 Panchang / Muhurta

- **输入**：天文历法（月相、宿、yoga、karana）。
- **规则**：天文计算 + 传统吉凶映射。
- **输出**：每日吉/凶时段、活动择时。
- **宣称机制**：天体位置 → 人事吉凶。
- **可检验命题**：按 Muhurta 选时的手术/旅行/签约结果是否优于随机？
- **实际情况**：**天文计算是精确的**（tithi/nakshatra 可算），但"吉凶映射"没有被现代对照试验支持；不同地区/流派差异大。
- **准确率来源**：
  1. **天文规律真实存在**（潮汐、光照、季节），但被外推到人事；
  2. **择时本身改变行为**（选安静时段、提前准备）；
  3. **文化共识与事后解释**。
- **可借**：时间窗、活动适配；**不可借**：把天文精度当预测精度。

### 2.6 西方 Electional Astrology / Planetary Hours / 年历 / 每日星座

- **输入**：出生盘/当下天象/行星时。
- **规则**：占星相位/宫位/行星时对应表。
- **输出**：择时建议、每日运势。
- **宣称机制**：行星位置 → 人事。
- **可检验命题**：按选举占星选时的项目成功率是否高于随机？
- **实际情况**：天象计算精确，解释未验证；每日星座是大众化产品，巴纳姆效应强。
- **准确率来源**：
  1. **模糊描述**；
  2. **基础率**；
  3. **自我实现**；
  4. **选择记忆**。
- **可借**：择时/节奏/反思框架；**不可借**：星座决定论。
- 参考：[Robson, Electional Astrology (1937)](http://iapsop.com/ssoc/1937__robson___electional_astrology.pdf)、[Barnum 效应研究](https://www.tandfonline.com/doi/abs/10.1080/00223980.1983.9915405)

### 2.7 现代 decision journal / N-of-1

- **输入**：个人记录、干预、结果。
- **规则**：前后对比、重复测量、预先定义结果。
- **输出**：某建议对"这个人"是否有效。
- **宣称机制**：不需要超自然机制，只看可观察变化。
- **可检验命题**：明确、可反驳。
- **准确率来源**：**真正的个人数据**，而不是象征系统。
- **可借**：这是验证"趋吉避凶"该用的方法；**不可借**：把它包装成命运。

## 3. "预测准确率"到底来自哪里

### 3.1 真实的规律（但通常不是它宣称的那条）

- 天文、季节、昼夜、生理节律、工作日/周末、财年/政策周期，确实会影响人的状态与事件概率；
- 但这些是**环境/时间规律**，不是"神煞/命盘/卦象"的因果；
- 系统把"时间规律"偷换成"符号规律"，准确率就被误记到符号头上。

### 3.2 模糊与多义

- "近期事业有变动""注意沟通""财务有波动"——几乎对任何人都成立；
- 多派解释允许事后挑选最贴切的一种；
- 越模糊，越"准"。

### 3.3 选择、记忆与确认偏差

- 记住命中的，忘记没中的；
- 主动寻找支持证据，忽略反例；
- 把"没有出事"解释成"避开了"，把"出事"解释成"没避对"。

### 3.4 社会协调与自我实现

- 大家都按黄历/六曜行动，行为本身改变了事件分布；
- 相信"今天适合谈判"，于是更自信、准备更充分，结果更好；
- 这不是预测准，而是**信念改变了行为**。

### 3.5 仪式、承诺与决策卫生

- 每日建议提供了一个"停下来想一下"的仪式；
- 具体的小行动（提前准备、暂缓不可逆决定）本身有价值；
- 价值来自**决策过程**，不是来自"算得准"。

### 3.6 计算精度 ≠ 预测精度

- 排盘、历法、天文位置可以算得很准；
- 但"算得准"只说明输入到符号的映射稳定，不说明符号到人事的映射有效；
- 这是传统系统最容易让人混淆的地方。

### 3.7 没有对照、没有预注册、没有盲评

- 绝大多数"灵验"是事后叙述；
- 没有"提前写下预测、到期核对、与随机基线比较"的流程；
- 没有这些，准确率无法被认真讨论。

## 4. 证据等级表（按我们的标准）

| 系统 | 计算/规则 | 对个人事件的预测 | 可借的部分 | 结论 |
|---|---|---|---|---|
| 黄历/通书 | 历法精确 | 无对照证据 | 活动分类、时间窗 | 文化工具，不是预测 |
| 紫微/八字 | 排盘确定、解释多派 | 无对照证据 | 领域/时间/关系语法 | 假设生成器 |
| 六爻/梅花/签 | 随机+解释 | 无对照证据 | 每日一问、聚焦 | 反思工具 |
| 六曜/十二直 | 简单循环 | 无对照证据 | 日语气氛 | 文化习惯 |
| Panchang/Muhurta | 天文精确 | 吉凶映射未验证 | 时间窗 | 天文真、解释待验 |
| 选举占星/星座 | 天象精确 | 无对照证据 | 择时/反思 | 巴纳姆风险高 |
| N-of-1/decision journal | 个人数据 | 可测量 | 验证方法 | 唯一能谈"准确率"的层 |

---

## 5. 我们怎么用它们（不重复它们的错误）

1. **只借语法，不借结论**：时间、领域、条件、动作、不确定性；不输出"命中注定"。
2. **把每条建议写成可检验命题**：谁、什么时候、做什么、怎么算有用/有害。
3. **个体因果优先**：同日同标签对所有人一样 → 不是个体因果；必须叠加你的领域/约束/状态。
4. **N-of-1 验证**：记录执行/有用/有害；两周复盘；没有增量就删。
5. **反巴纳姆检查**：建议必须具体到领域/动作/时间；模糊话不发。
6. **不制造恐惧**：忌 = 暂缓/换法，不是"大凶"。
7. **不碰高风险**：医疗/投资/法律只提示找专业人。

---

## 6. 一句话总结

> 这些系统的"准确率"不来自它们宣称的因果，而来自：**真实的时间规律 + 模糊多义 + 选择记忆 + 社会协调 + 仪式性行动 + 缺乏对照**。  
> 我们可以借它们的"内容语法"和"仪式感"，但必须用个体因果与 N-of-1 重新验证；否则只是把旧算命换成了新界面。
