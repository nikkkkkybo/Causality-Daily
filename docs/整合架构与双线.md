# 整合架构：通线、个体线与"强潜意识"

> 日期：2026-11-12　状态：总体设计
> 目的：把你给的零散方向（Human 3.0、命理、心理学、微信推送、单应用、问卷、保险箱）整合成一套能跑的架构；并明确：**没有个体因果基线时走"通线"（通用读者版），有基线时走"个体线"，基线作为"强潜意识"隐性加权。**
> 边界：不诊断、不评分、不预测命运、不做医疗/法律/投资建议；通线与个体线都不是事实结论。

---

## 0. 一句话

- **通线**：不知道你是谁，就按"一个关心因果、需要判断的读者"来推；只讲世界链，不假装懂你。
- **个体线**：你给过基线，系统就把你的领域、时间、约束、杠杆当作**强潜意识**——它影响我挑什么、怎么连、怎么排，但不跳出来命令你，也不在页面上贴"你的档案说……"。
- 两条线共用同一套底层（信号、出处、结构、表达、反馈、隐私、投递），差别只在**排序权重与呈现**。

---

## 1. 分层：从世界到个人

| 层 | 名称 | 做什么 | 缺了会怎样 |
|---|---|---|---|
| L0 | 世界信号 | 订阅、抓取、时间窗、来源多样性 | 无米下锅 |
| L1 | 证据与出处 | 出处链、同题去重、独立性、时间戳 | 把转述当独立证据 |
| L2 | 结构 | 跨领域同构、因果骨架、模板（外化/伪形/长周期等） | 只有新闻列表，没有链 |
| L3 | **通线** | 默认读者假设；世界相关性排序 | 不知道你是谁时硬装懂你 |
| L4 | **个体线** | 基线：领域、时间、关系、约束、杠杆；强潜意识 | 推送泛化，无法回答"为什么与我有关" |
| L5 | 心理与行为 | 价值观、负荷、改变阶段、自我效能；调语气/长度/行动性 | 信息对但时机/形态不对 |
| L6 | 表达 | 长度、链条格式、个体因果两行、不确定说明 | 好内容读不下去 |
| L7 | 反馈与验证 | 末尾备注、决策日记、N-of-1、盲评、消融 | 无法知道有没有用 |
| L8 | 隐私与安全 | A/B/C/D 分层、保险箱、同意、审计、删除 | 越界采集，信任崩塌 |
| L9 | 运行与投递 | 本地应用、定时、微信/手机、静态页 | 生成完送不到你手里 |

> 你之前给的是 L3/L4/L9 的碎片；这里补的是 L0–L2、L5–L8，以及它们之间的接口。

## 2. 两条线：触发、输入、输出

| | **通线（general）** | **个体线（individual）** |
|---|---|---|
| 触发 | 没有基线，或基线不完整 | 有可用基线（至少领域权重 + 当前问题） |
| 输入 | 候选信号 + 来源/结构 | 候选信号 + 基线（强潜意识） |
| 排序 | 世界相关性：来源、独立源、结构强度、时效、新颖 | 个体相关性：领域权重 × 路径影响 × 时机 × 可行动性；世界分作底 |
| 呈现 | 判断 + 3 条链（因/果/我的链路/可能错） | 同左，加"为什么与你有关""你在哪一段"；时间窗 |
| 口吻 | 对"一个读者"说话 | 对"你"说话，但不贴标签、不引用档案 |
| 风险 | 泛、无关、像资讯摘要 | 过滤气泡、自我实现、过度拟合 |
| 默认 | 无基线时自动走 | 有基线时自动走；可手动关闭 |

**中间态：轻个体线（partial）**
- 只有领域权重或只有当前问题 → 只做排序，不写"你在哪一段"；页面注明"轻个体化"。
- 基线过期/重大生活事件后 → 自动降级为通线，直到复评。
- 任何一条个体结论无法落到可观察后果 → 不写。

**切换规则（建议默认）**
- 基线完整度 < 0.4 → 通线；
- 0.4–0.7 → 轻个体线；
- ≥ 0.7 → 个体线；
- 用户可手动 `--mode general|individual|auto`；默认 auto。

## 3. "强潜意识"到底是什么

### 3.1 定义

> 强潜意识 = 由个体因果基线导出的、持续存在、权重较高、但不以命令/标签形式出现的**注意力先验**。

它回答的不是"你喜欢什么"，而是：

- 什么能**到达**你（时间、角色、责任、地理）；
- 什么能**作用**于你（领域、关系、资源）；
- 你能**动**什么（杠杆、约束、可行动性）；
- 你现在**处在**哪一段（阶段、负荷、改变阶段）。

### 3.2 强 vs 弱

| | 强潜意识（基线） | 弱潜意识（末尾备注/偶发话） |
|---|---|---|
| 来源 | 问卷 + 复评 + 重大事件 | 事报末尾备注、聊天里的随口一句 |
| 持久性 | 季度/半年 | 几天到几周，会衰减 |
| 权重 | 高，改变候选池与排序 | 低，只做微调 |
| 呈现 | 不显示成"档案"，最多一句"为什么与你有关" | 不显示 |
| 更新 | 复评/重大事件触发 | 每次提交即更新，快速衰减 |

### 3.3 它如何起作用（而且不越界）

- **进入候选池**：与高权重领域/约束无关的信号，降权或只"存目"；
- **改变排序**：个体路径强度 × 领域权重 × 时机 × 可行动性；
- **改变呈现**：是否展开、给不给行动线索、要不要反方；
- **不做什么**：不替你做决定、不声称"你会怎样"、不把命理术语写出来、不把基线当事实证据。

### 3.4 防"强"变成"偏"

- **新颖配额**：每期至少 20–30% 来自舒适区之外（弱相关但结构重要），避免回音室；
- **反方/替代解释**：个体线也要保留一句"也可能是……"；
- **基线可审**：一句话说明"为什么与你有关"，可点开看依据（领域/路径），可修改；
- **定期关掉基线盲测**：每月一次"通线 vs 个体线"盲评，防止自我实现；
- **衰减与复评**：备注权重按天衰减；基线 6 个月复评，重大事件（换工作、搬迁、疾病、关系变化）触发提前复评；
- **不可行动就不推**：纯背景信息进"存目"，不占正文。

---

### 3.5 意向潜意识 vs 因果强潜意识（2026-11-13 补充）

这是两个不同的东西，不能混：

| | **意向潜意识** | **因果强潜意识** |
|---|---|---|
| 来源 | 你的末尾备注、你随口说的角度、你的偏好/好奇 | 问卷/档案：领域权重、目标、约束、位置、时间窗 |
| 性质 | 你主动给出的"我想看什么" | 系统从你的因果位置推出的"什么与你有关系" |
| 持久性 | 短期（几天到几周），会衰减 | 长期（季度/半年复评） |
| 权重 | 轻，只做注意力微调 | 强，改变候选池与排序基线 |
| 作用 | 重排、加一句提示、触发复评 | 排序主权重、呈现形态、可行动性 |
| 能否写档案 | **不直接写**；只进校准/短期增量 | 是档案本身；改动必须显式复评 |
| 失败模式 | 把一句偏好当命令、过拟合当天情绪 | 把旧基线当命运、回音室、自我实现 |

**交互规则**：
1. 世界证据是门；因果强潜意识决定"对你多重要"；意向潜意识只在边际上重排。
2. 意向不直接改档案；如果同一意向反复出现，才升级为"复评候选"，由你确认后才改基线。
3. 两者冲突时，先按因果基线排，再让意向做小幅调整；页面只给一句"为什么与你有关"，不显示是哪一层在起作用。
4. 审计分开记录：`baseline_weight` 与 `intent_delta` 不混在一个数里；这样消融时才知道是谁的贡献。
5. 意向可撤回、可清空；因果基线可复评、可降级；两者都不等于命令或命运。

**当前实现映射（已拆分，2026-11-13）**：
- `notes` + `calibrate` 是**意向层**：读备注 → 生成 `intent_delta`，不再写回档案 `domains`；
- `profile`/`vault` 是**因果强层**：领域、约束、位置、目标；
- `calibrate.effective_features` 返回 `baseline` + 独立的 `intent_delta`；`personalize` 以 `INTENT_FACTOR=0.5` 把意向增量叠加到排序分，基线本身不被备注改写；
- 这样消融时可以单独关闭意向层，看它到底贡献了多少。

## 4. 排序：一个可解释的公式

```text
world_score(E) = source_prior × independence × structure_strength × timeliness × novelty

causal_score(E) =
    Σ_domain  baseline_weight_d × impact(E, d) × path_confidence(E, d)
  × timeliness(E, personal_window)
  × actionability(E, constraints, leverage)

final = world_score × (1 + α × causal_score + β × intent_delta)
```

- `world_score`：通线也要算，个体线不能绕过；
- `causal_score`：来自**因果强潜意识**（档案基线），决定"这条对你多重要"，不改变真值；
- `intent_delta`：来自**意向潜意识**（备注/一句角度），只做小幅重排；`β ≪ α`，且不写回档案；
- `psychological_fit` 只决定长度/语气/是否给行动建议，不决定真假；
- 所有分项都记录在隐藏审计里，页面只给一句人话解释。

## 5. 呈现：两种模板

### 5.1 通线

```text
今日判断（一句）
链一/二/三：因 → 果 → 我的链路 → 可能错在哪
今日算法链（来源、筛选、结构、强度、不确定）
页脚：推断，不是结论
```

### 5.2 个体线

```text
今日判断（一句，仍是对世界的判断）
链一/二/三：因 → 果 → 我的链路 → 可能错在哪
           ＋ 为什么与你有关（领域/目标/约束，一句）
           ＋ 你在哪一段（旁观/受影响/可行动；时间窗）
今日算法链（含"本期用了多大比例的个体先验"）
页脚：推断，不是结论；个体部分是我的假设，不是你的档案
```

### 5.3 轻个体线

只做排序，不加"你在哪一段"；可加"为什么与你有关"一句，但注明"轻个体化"。

## 6. 反馈与验证：让"强潜意识"可纠错

1. **末尾备注**（弱潜意识）：即时、快速衰减；
2. **7 天校准**：每天一句"与你有关吗"（有关/无关/说不清），一周后微调领域权重；
3. **决策日记**：记录"因为这条做了什么/没做什么"，这是个体因果的真正检验；
4. **N-of-1**：把"个人后果"登记为可观察项，到期结算；只看命中/偏差，不宣称命理准确；
5. **盲评**：每月一次通线 vs 个体线盲评；不让系统知道哪版是个体线；
6. **消融**：关闭领域权重/时间层/心理层，看效果变化；无增量就降权；
7. **复评**：6 个月或重大事件；只记录变化，不评分。

---

## 7. 隐私与安全：强潜意识必须住在保险箱旁边

- **A 可回答**：时区、领域权重、非敏感目标/约束、信息习惯；
- **B 本地私密**：近期事件、负荷、财务压力（粗）、睡眠（粗）；
- **C 保险箱**：出生数据、健康细节、关系细节、资产负债、创伤；默认不读取，按次解锁，永不外发；
- **D 永不采集**：身份证、密码、他人隐私、病历原件；
- 强潜意识只用 A/B 的**派生特征**；C 层不参与日常排序；
- 模型调用只发 A/B 的脱敏派生特征；C 层不发送；
- 基线可导出/删除；解锁有审计；用户可随时关掉个体线。

## 8. 我补的层（你未提但必须有的）

1. **证据层**：出处链、独立性、时间戳——否则个体线只是在"更懂你地传谣"；
2. **结构层**：跨领域模板——否则个体线只是"你关心的新闻"；
3. **时间层（现实优先）**：截止日、财年、项目节点、政策窗口；命理时间只作内部标签；
4. **可行动性层**：没有杠杆/授权/时间，就不给"建议"，只作背景；
5. **心理层**：负荷高时缩短、给确定性；改变阶段早时给知识、晚时给行动；
6. **不确定性层**：每条链标强度、可能错在哪、替代解释；
7. **新颖配额**：防止强潜意识变成回音室；
8. **降级/回退**：基线缺失/过期/异常 → 通线；
9. **表达层**：长度、时间、渠道（本地应用/微信/静态页）；
10. **运行层**：定时、投递、失败重试、离线兜底；
11. **审计层**：隐藏元数据记录用了哪些层/模板/权重；
12. **伦理层**：不诊断、不命运预测、不医疗/投资建议、不歧视、可删除。

## 9. 实施顺序

1. **profile schema + provenance**：字段带 `source(H/M/P)`、`use`、`failure_mode`、`confidence`；
2. **mode 选择**：`general / light / individual`，auto 规则与降级；
3. **排序 MVP**：world_score + personal_score；通线先跑通，个体线作为可选乘子；
4. **模板分支**：通线模板不变；个体线加两行；轻个体线只加一句；
5. **问卷导入**：JSON → 派生特征；原始答案可留可删；保险箱占位；
6. **反馈闭环**：备注/7 天校准/决策日记；
7. **验证**：盲评、消融、复评；
8. **投递**：本地应用 → 微信/手机 → 定时；
9. **测试**：模式切换、降级、隐私、审计、模板不越界。

---

## 10. 默认决策（可改，但我先按这个做）

- 无基线 → **通线**，页面注明"通用版"；不假装个体化；
- 有基线 → **个体线**，基线权重高但不显示档案；
- 基线不完整 → **轻个体线**；过期/重大事件 → 先降通线，复评后再升；
- 强潜意识只用 A/B 派生特征；C 层不进日常排序；
- 每期保留 20–30% 新颖/弱相关；每月盲评；6 个月复评；
- 个体结论必须带"可能错在哪"；不可行动的不写成建议。
