# 溯源工程：从"趋吉避凶"往上找源头（第一轮）

> 日期：2026-11-13　状态：方法与首轮图谱
> **边界：本工程只做"谱系/传承"——从哪来、经谁、何时、改了什么、哪段失传或托名；不评价好坏、准不准、有效无效。** 文中的 A/B/C/D 只表示"文献确定性"（有原典/有研究/仅转述/源头不明），不表示价值判断。
> 我理解你的要求：不是"搜到别人怎么说"，而是**把每一环的依赖关系找出来，再逐环验证**；先广度收资料，再收束成图，再对每条边做证据核对。
> 这一轮先交方法 + 首轮图谱 + 待验证清单；不把"传说/百科"冒充已证事实。

---

## 1. 方法：广度 → 收束 → 逐边验证

```text
① 广度：收集系统、文本、考古物、学术研究、域外传播
② 收束：把"谁依赖谁"画成有向图（系统/文本/器物/制度）
③ 逐边：对每条边找证据，标 A/B/C/D
④ 再收束：合并同源，区分"文本依赖 / 功能相似 / 后世附会"
⑤ 输出：源头候选 + 不确定点 + 可继续核对的馆藏/论文
```

### 证据分级

| 级别 | 含义 | 例子 |
|---|---|---|
| **A** | 一手材料：出土器物、原典、档案、同时代记录 | 睡虎地秦简《日书》、汝阴侯墓式盘、甲骨卜辞 |
| **B** | 学术研究：同行评议论文、权威书目、考古报告 | 式盘研究、六壬研究、天文学史 |
| **C** | 传统/百科/宗教文化解释：有参考价值，但不是证明 | 神社历注说明、百科条目、术数传承叙述 |
| **D** | 现代大众/商业内容：只能当线索 | 每日运势 App、营销文章 |

**规则：A 能证明"存在/年代/文本"；B 能支持"依赖/传播"的判断；C/D 只能提出假设，不能当结论。**

## 2. 首轮图谱：以"六曜"为例

### 2.1 当前能说出的链

```text
六曜（日本，江户以后普及的历注）
  ← 六壬時課（中国传来的时刻占卜）
    ← 六壬 / 大六壬（中国式占体系）
      ← 式占 / 式盘（汉代已有实物）
        ← 阴阳五行、干支、天文历法
          ← 占卜/祭祀/决策仪式（更早的龟卜、蓍筮等）
```

### 2.2 逐边证据状态

| 边 | 说法 | 证据 | 状态 |
|---|---|---|---|
| 六曜 ← 六壬時課 | 日本神社历注说明称六曜源自中国"六壬时课"，由时刻占变为日占 | 大崎八幡宮《暦の意味》[C] | **待学术确认**：C 级，不能单独定论 |
| 六壬時課 ← 六壬 | 六壬时课是六壬体系中的"时"占用法 | 六壬研究论文/书目 [B/C] | 需核对具体文本与年代 |
| 六壬 ← 式占/式盘 | 六壬以式盘/十二天将/四课三传为操作框架；汉代已有式盘实物 | 汝阴侯墓式盘（西汉初）[A]；中国古代式盘研究 [B] | **较强**：式占存在；但"六壬"之名/体系是否直接源于汉代式盘，需谨慎 |
| 式盘 ← 阴阳五行/干支/天文 | 式盘布局依赖方位、干支、天文历法 | 考古报告、天文学史 [A/B] | **较强** |
| 占卜/祭祀 ← 更早 | 甲骨卜辞、蓍筮、祭祀决策 | 甲骨卜辞 [A]；《周易》[A/B] | **存在**，但"单线演化"不成立 |

### 2.3 关键不确定点

- "六曜"是否**直接**从"六壬时课"演化，还是日本本土历注与六壬**功能相似**后被附会？需要日本历法史论文核对。
- "六壬"作为一个**命名体系**何时成立？汉代式盘能证明"式占"，不能直接证明"六壬"文本已存在。
- 六壬的"六"、十二天将、四课三传的来源，有天文/阴阳/术数多重成分，不宜压成单因。

### 2.4 再往上：可能的共同源头

- **时间测量/天文历法**：方位、干支、节气、月相；
- **二元/周期分类**：阴阳、五行、天干地支；
- **占卜/神谕/仪式**：把不确定交给可操作的程序；
- **社会制度**：历官、王权、祭祀、择日协调；
- **认知**：模式识别、控制感、意义建构。

## 4. 收束：不是一棵树，而是一张图

首轮看下来，至少有五条"根"反复出现：

1. **天文/时间**：观测、历法、周期；
2. **分类**：阴阳、五行、干支、方位；
3. **占卜程序**：龟卜、蓍筮、式盘、签卦；
4. **制度**：王权、祭祀、历官、行业；
5. **认知/社会**：不确定性、控制感、协调、叙事。

"六曜"是这张图上的一个晚期小节点，不是从某个"第一因"直线长出来的。**溯源的结果不是"找到唯一源头"，而是"看清哪些边有证据、哪些边是后世附会"。**

## 5. 待验证清单（下一轮按优先级）

1. **六曜 ← 六壬时课**：找日本历法史/民俗学论文（不是神社说明），核对"六曜"名称最早出现年代与传播路径。
2. **六壬 ← 式盘**：核对《隋书·经籍志》等书目中的六壬类文献；区分"式占"与"六壬"的命名年代。
3. **紫微 ← 陈抟/印度影响**：做版本学核对（《紫微斗数全书》早期版本、托名情况），不把"传为"当"确证"。
4. **四柱 ← 李虚中/徐子平**：核对唐宋文献与后世建构，区分"三柱/四柱"演变。
5. **西方占星 ← 两河**：核对 Enuma Anu Enlil → 希腊化占星的传播证据（学术史）。
6. **印度 Panchang ← 吠陀**：核对 Vedanga Jyotisha 与后世 Panchang 的连续/断裂。
7. **共同认知机制**：用心理学/实验研究（巴纳姆、控制感、预测加工）解释"为什么这些系统看起来有效"，与历史链分开写。
