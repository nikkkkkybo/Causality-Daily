# 推送通道：不必绑死微信

> 日期：2026-11-13　状态：已实现 ntfy / Bark / Telegram / ServerChan 四种；零月费。
> 默认 `cloud --channel auto`：按已配置的 Secret 自动选一个；都没配就跳过推送，报告照常生成。

## 1. 四种通道对比

| 通道 | 适合 | 注册 | 费用 | 在中国大陆的可用性 | 备注 |
|---|---|---|---|---|---|
| **ntfy.sh** | Android / 跨平台 / 不想注册 | 不需要 | 免费 | 一般可用；若不稳定可自建 | 订阅一个随机 topic 即可；topic 等同于密码 |
| **Bark** | iPhone / iPad | 不需要 | 免费 | 通过 APNs，通常稳定 | App Store 安装，复制设备 key |
| **Telegram Bot** | 已用 Telegram | 需要 BotFather | 免费 | 需能访问 Telegram | 最标准的 Bot API |
| **ServerChan** | 想收微信 | 需要 | 有免费额度 | 可用 | 第三方服务，非微信官方 |
| 邮件 / 飞书 / 企微 | 企业/通用 | 各自需要 | 各自规则 | — | 还没接，可后续加 |

**最容易达成**：
- iPhone：**Bark**（装 App → 复制 key → 加 Secret，3 步）；
- Android/不想注册：**ntfy.sh**（装 App → 随机 topic → 加 Secret）；
- 已有 Telegram：**Telegram Bot**；
- 只想收微信：ServerChan（有额度限制）。

## 2. 配置

在仓库 Settings → Secrets and variables → Actions 里，任选**一个**加：

| Secret | 说明 |
|---|---|
| `NTFY_TOPIC` | 例如 `cl-8f3k2m9q7x`；只能字母/数字/`_`/`-`，1–64 位；别用可猜的短词 |
| `BARK_KEY` | Bark App 里的设备 key |
| `TELEGRAM_BOT_TOKEN` + `TELEGRAM_CHAT_ID` | BotFather 的 token；chat_id 可通过给 bot 发消息后调 `getUpdates` 获取 |
| `SERVERCHAN_KEY` | Server酱 SendKey |

工作流已经把以上都作为环境变量传入；`auto` 的选择顺序是：
`SERVERCHAN_KEY → NTFY_TOPIC → BARK_KEY → TELEGRAM_*`。
想强制某个通道：`cloud ... --channel ntfy|bark|telegram|serverchan|none`。

## 3. 测试与边界

```powershell
python -m causal_ledger cloud --config config\feeds.json --reports reports --no-fetch --channel none
python -m causal_ledger cloud --config config\feeds.json --reports reports --no-fetch --channel ntfy
```

- Key/token 只放 GitHub Secret，不写进代码、不进日志；
- ntfy.sh 是公共服务器：知道 topic 的人就能订阅；topic 要随机、够长；敏感内容不要走公共 topic；
- 推送只是"报告链接 + 一句摘要"，完整内容在静态页；
- 所有通道都是可选的，没配置时报告仍生成、部署照常，只是不推送。
